# 🚀 Task Manager

A modern and responsive Task Management System built using HTML, CSS, JavaScript, Bootstrap, and LocalStorage.

## ✨ Features

- ✅ Add New Task
- ✏️ Edit Task
- 🗑 Delete Task
- 💾 LocalStorage Support
- 📅 Due Date
- 📱 Responsive Design
- 🎨 Modern UI
- ⚡ Fast Performance

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- LocalStorage

## 📂 Project Structure

```
Task-Manager/
│
├── index.html
├── style.css
├── script.js
├── README.md

```





Open **index.html** in your browser.
